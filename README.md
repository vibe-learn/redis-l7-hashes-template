        # redis — Хеши — объекты внутри ключа

        Homework-шаблон для урока **l4_hashes** (Хеши — объекты внутри ключа) на платформе Vibe Learn.

        ## Что делать

        Реализуй UserProfileRepo с двумя бэкендами: StringJSONRepo и HashRepo. Микро-бенчмарк
меряет память и latency на 10k операций GET/SET/INCR. Тесты проверят корректность обоих
репо и выводят cравнительный отчёт.

## Контекст (из transfer-задачи урока)

У тебя 5 миллионов профилей юзеров в Redis. Каждый — JSON-строка 800 байт.
Память: ~4GB. Memory limit подходит к 80%. Команда обсуждает: «купить инстанс с
бОльшей памятью» vs «переписать на hashes». Подсчитай примерную экономию памяти
при переходе на hash, какие риски в переходе, как мигрировать без даунтайма.

## Recap из урока

- Hash — map полей внутри ключа. HSET/HGET по полю O(1), HGETALL O(N) от полей.
- Маленькие хеши (≤128 полей × ≤64 байта) кодируются как **listpack** (ziplist до Redis 7.0) — заметно компактнее hash-таблицы. Превышение лимита необратимо переключает на hashtable.
- Хеш > string-JSON когда нужны атомарные апдейты полей или экономия памяти. String-JSON > hash когда объект всегда читается/пишется целиком.
- HINCRBY атомарно увеличивает целочисленное поле — счётчики (followers, views) идеальны внутри хеша.
- Не делай HGETALL на гигантских хешах. Используй HSCAN или шарди объект на несколько ключей.

        ## Как работать

        1. Платформа Vibe Learn создаёт копию этого репо в твоём GitHub-аккаунте по клику «Начать домашку» на странице урока (через GitHub `/generate`, codecrafters-pattern).
        2. Склонируй копию локально, реализуй TODO в `main.go`, прогони тесты, запушь.
        3. CI (`.github/workflows/ci.yml`) запускает `go vet` + `go test ./...` на каждый push. Платформа слушает результат через webhook от GitHub Actions и обновляет статус домашки на странице урока.

        ## Локальное окружение

        - Go 1.22+
        - Docker + docker-compose — `docker compose up -d` поднимает single-node Redis 7 на `localhost:6379` (с включёнными keyspace-notifications и AOF). Адрес переопределяется через env `REDIS_ADDR`.

        ## Запуск

        ```bash
        # Поднять локальный Redis
        docker compose up -d

        # Прогнать тесты (интеграционный включается через REDIS_INTEGRATION=1)
        go test ./...
        REDIS_INTEGRATION=1 go test ./...

        # Запустить main (печатает marker; замени stub на реализацию)
        go run .
        ```
